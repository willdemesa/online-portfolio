# Wilfredo A. De Mesa Jr. — IT Student Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Project files

- `index.html` — website content and page structure
- `style.css` — colors, layout, responsive design, and styling
- `script.js` — mobile navigation, current year, and contact form behavior
- `README.md` — setup and editing instructions

## How to run

1. Download and extract the project ZIP.
2. Open the extracted `arjey_portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Keep all three website files (`index.html`, `style.css`, and `script.js`) in the same folder.

## Personalize the website

- Edit the About Me section in `index.html`.
- Replace the sample project descriptions with your real projects.
- Update the skills to match what you have learned.
- In `script.js`, change `your-email@example.com` to your real email address so the contact form can prepare an email.
- Add your own photo or social-media links if desired.

## Notes

The contact form uses the visitor's default email application. It does not save or send messages to a server. A backend service is needed for a website contact form that submits messages directly.
